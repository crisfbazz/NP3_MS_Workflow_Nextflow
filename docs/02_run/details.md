# Pré-processamento de Dados

Nesta seção, abordamos os passos iniciais para a preparação dos arquivos brutos de MS.

## Requisitos de Entrada
Os arquivos devem estar preferencialmente no formato `.mzXML` ou `.mzML`.

!!! note "Dica Importante"
    Certifique-se de que a calibração de massa foi aplicada antes de exportar os dados.

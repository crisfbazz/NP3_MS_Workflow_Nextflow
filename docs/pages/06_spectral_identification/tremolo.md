## Step 6: Command **tremolo** 
 
Runs the spectral identification of a collection of consensus spectra against the In-Silico predicted MS/MS spectrum of 
Natural Products Database[^1] (ISDB) for 170 602 Natural Products from the Universal Natural Products Database[^2] 
(UNPD)  using the tremolo tool[^3] to retrieve library annotations. This tool can only be executed in Unix OS and for 
data in positive ion mode. 

The Step 6.1 corresponds to the GNPS2 Library Search and is described in the next [section](gnps_library_search.md).

The NPClassifier[^4], NPAtlas[^5] and ClassyFire[^6] solutions were used to add origin and class information to 
the UNPD compounds. NP³ MS Workflow will retrieve this information together with the library annotations.
 
At the end of the spectral identification step, a curation is performed to select the best UNPD result from 
the top k identifications of each spectra and to score them with a personalized
criteria. Additionally, a superclass grouping of the NPClassifier result was proposed by the NP³ team and is also 
applied here for the curated superclass. 

Finally, the final identification curation is performed (more details in [next section](final_identification_curation.md)).

A binary version of the tremolo tool is freely available for download in the following
[link](http://proteomics.ucsd.edu/software-tools/tremolo/).
 
## Parameters:

For the complete list of parameters run:
 
```{ .text .copy }
node np3_workflow.js tremolo --help
```

Parameters for the command *tremolo*:
 
- *\-o, \-\-output_path <path>* :     path to where the spectral library search results will be stored. This is usually the 'identifications' folder present in the final result.
- *\-g, \-\-mgf <file>*       :      path to the input MGF file with the MS/MS spectra data to be searched and identified
- *\-c, \-\-count_files [name]*       :      optional paths to the count CSV files, separated by a comma and no space, as outputted by the NP³ MS workflow where the identifications should be added as new columns. The top_k search results for each msclusterID will be added in additional identification columns generated by tremolo, then the curated and best results will also be added in other columns. The count files header must be in the first row. (default: "")
- *\-z, \-\-mz_tolerance <file>*       :      the tolerance for parent mass search in Daltons. Set a small tolerance for dereplication using parent ion mass as prefilter, keeping in mind the resolution of your data. Increase to the wanted range for variable dereplication search (ex: 100 or 200 Da) Caution as this will also increase calculation times! (default: 0.025)
- *\-s, \-\-similarity <file>*       :      the similarity threshold that determines if two spectra are the same. Should be kept low when using in-silico DB, as recommended by the authors. Typically, 0.2 to 0.3 (default: 0.2)
- *\-k, \-\-top_k <file>*       :      defines the maximal number of results returned by the tremolo tool, e.g. number of identifications by msclusterID
- *\-v, \-\-verbose <file>*       :      for values X > 0 show the scripts output information (default: 0)
- *\-h, \-\-help <file>*       :      output usage information
 
## Results
 
Two files are created inside the 'output_path' folder (this folder is created if missing):
 
- 'logTremolo' a text file with the tremolo tool output information;
- 'tremolo_results.csv' a CSV file with the tremolo search results for each spectra SCANS present in the provided MGF file. 
Each top_k result is presented in a separated row in this table.
    
When the count_files are provided, the tremolo results are aggregated by spectra and the following columns are added to 
the tables:

## UNPD Identification Curation

A curation of the identification results was proposed to score and rank the best identification from the UNPD-tremolo. 
The curation is executed after the library annotations are merged to the count_files tables. Some chemical criteria 
were defined to automatically select the best annotations from the `top_k` results. Additionally, a chemical grouping of 
the NPClassifier superclass were proposed by the NP³ team to ease the chemical understanding of the best identifications.

The curation starts by selecting the best result among the `top_k` identifications for each identified spectra in UNPD 
and then extract its value for each  identification column, as follows:

1. The best result is defined as the library annotation with the higher tremolo_MQScore which have 
2. tremolo_mzErrorPPM < 20 if any, otherwise it is defined equals to the identification with the smaller 
3. tremolo_mzErrorPPM rounded in the first decimal place which have the higher tremolo_MQScore;
2. The best result position is set in a new column named 'tremolo_best_position' which will store the index of the 
3. best result among the `top_k` library annotations of each spectra;
3. New identification columns are created with only the best selected result (from the 'tremolo_best_position') and 
4. are named equal to the identification column names plus a suffix equals to '_best'.
    - Additionally, it is created the column 'tremolo_NPClassifier_superclass_clean_best' with only the superclass 
    - assigned by NPClassifier when the result from ClassyFire is also present and separated by a pipe '|' (only the 
    - best result before the pipe).

After the best UNPD result were selected and their information extracted, the curation proceeds to a categorization 
and scoring of the best result. Ten categories and scores were defined to group the best results according to the 
reliability of their matches or to put them out of the analysis, using the criteria presented below:

| Tremolo UNPD Category | Score | Criteria | 
| :--------------- | :---: | :------------------------------------: | 
| Top1\|mqs>=0.5 | 100 | mzE <= 20 and nsP >= 6 |
| Top2\|0.4<=mqs<0.5 | 80 | mzE <= 20 and nsP >= 6 |
| Top3\|sp<6 mqs>=0.5 | 60 | mzE <= 20 and nsP < 6 |
| Top4\|sp<6 0.4<=mqs<0.5 | 50| mzE <= 20 and nsP < 6 |
| Top5\|mqs>=0.2 | 45 | mzE <= 20 and nsP >= 6 and mqs<0.4 |
| Analog1\|mqs>=0.5 | 40 | mzE > 20 and nsP >= 6 |
| Analog2\|0.4<=mqs<0.5 | 30 | mzE > 20 and nsP >= 6 |
| Analog3\|sp<6 mqs>=0.5 |  20 | mzE > 20 and nsP < 6 |
| Analog4\|sp<6 0.4<=mqs<0.5 | 10 | mzE > 20 and nsP < 6 |
| Analog5\|mqs>=0.2 | 5 | mzE > 20 and nsP >= 6 and mqs<0.4 |
| out | 0 | did not passed in any category - unreliable identification |
  
* Where mqs is the tremolo_MQScore_best, nsP is the tremolo_numSharedPeaks_best and mzE is the tremolo_mzErrorPPM_best 
values. 

The defined category of each final best UNPD identification is stored in the column 'tremolo_UNPD_category_best' and 
its corresponding score is stored in the column 'tremolo_UNPD_score_best'.

#### Superclass grouping

Finally, the curation of the UNPD identification also defines and creates 10 groupings of the superclasses from the 
NPClassifier. In UNPD, there are 94 superclasses from the NPClassifier, which is a very large number for a fast analysis. 
Here the NP³ team proposed a groupings with 10 major superclasses using a chemical reasoning to group related 
superclasses in a Drug Discovery perspective. The major superclasses groupings are presented in the table below:

| Major Superclass Group | NPClassifier Superclasses |
| :---------- | :---------------: |
| Aminoacids_and_Peptides_and_OtherNComp | "Amino acid glycosides", "Mycosporine derivatives", "Oligopeptides", "Small peptides", "Aminosugars and aminoglycosides", "Diazotetronic acids and derivatives", "Mitomycin derivatives", "Organic nitrogen compounds", "Nucleosides, nucleotides, and analogues", "Nucleosides" |
| Alkaloids_and_Lactams | "Alkaloids and derivatives", "Anthranilic acid alkaloids", "Lysine alkaloids", "Guanidine alkaloids", "Histidine alkaloids", "Ornithine alkaloids", "Peptide alkaloids", "Proline alkaloids", "Pseudoalkaloids", "Tetramate alkaloids", "Miscellaneous alkaloids", "Nicotinic acid alkaloids", "Serine alkaloids", "Tryptophan alkaloids", "Tyrosine alkaloids", "$\beta$-lactams", "$\gamma$-lactam-$\beta$-lactones" |
| Terpenes_and_Carotenoids | "Diterpenoids", "Meroterpenoids", "Monoterpenoids", "Sesterterpenoids", "Triterpenoids", "Steroids", "Sesquiterpenoids", "Apocarotenoids", "Carotenoids (C40)", "Carotenoids (C45)", "Carotenoids (C50)" |
| Fatty_Acids_and_Lipids | "Fatty Acids and Conjugates", "Fatty acyl glycosides", "Fatty acyls", "Fatty amides", "Fatty esters", "Lipids and lipid-like molecules", "Docosanoids", "Eicosanoids", "Glycerophospholipids", "Glycerolipids", "Octadecanoids", "Sphingolipids", "Hydrocarbons", "Hydrocarbon derivatives" |

| Flavonoids_and_Phenolic_derivatives | "Alkylresorcinols", "Flavonoids", "Isoflavonoids", "Phenolic acids (C6-C1)", "Phenylethanoids (C6-C2)", "Phenylpropanoids (C6-C3)", "Phloroglucinols", "Phenylpropanoids and polyketides" |

Next, it is created the column 'tremolo_curated_superclass' that receives the result of the best tremolo superclass 
for the spectra that have tremolo_UNPD_score_best > 0 (or tremolo_UNPD_category_best != 'out'). 
This column is then mapped to the superclasses grouping defined above and stored in column 
'tremolo_curated_superclass_grouping'. If multiple superclasses were assigned to a spectra, they are separated by a ':'. 
Finally, for each curated superclass grouping, it is created a column named 
'tremolo_curated_superclass_GR_\<curated superclass grouping\>' with 0 or +1 values that counts how many times the 
curated library annotation from UNPD-tremolo appeared in the corresponding curated superclass grouping (zero, one or 
more times).

At the end, the final identification curation is performed ([next section](final_identification_curation.md)). And then, the final chemical reports are created.
